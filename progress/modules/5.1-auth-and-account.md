## Purpose
Signup/login and the workspace model that lets an agency manage multiple client brands under one login.

## Acceptance criteria
- [ ] Email + Google OAuth signup/login working
- [ ] Workspace (org) model: a workspace can contain multiple brands
- [ ] Roles implemented: Owner, Member, Viewer
- [ ] RLS policies scoped to workspace membership on every table created from this point on
- [ ] Email normalized before any uniqueness check (lowercase, strip +tag suffixes, strip dots for Gmail-style addresses) — both raw and normalized email stored
- [ ] At most one workspace on the Free plan per normalized email as Owner, enforced at workspace-creation time (not just signup, since a paid workspace can later downgrade to free); attempting a second shows a clear message ("this email already has a free workspace — upgrade it or log in"), never a silent block
- [ ] This limit applies to Free-plan ownership only — being invited as Member/Viewer to any number of other workspaces (the agency use case) is unrestricted
- [ ] Signup endpoint rate-limited by IP as a second layer against scripted mass signups, same pattern as the free-check tool (5.11)
