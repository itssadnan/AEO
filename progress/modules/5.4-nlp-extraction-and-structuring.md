## Purpose
Turns Gemini's raw answer into structured data: mentioned, position, reasoning, sentiment, competitors, citation types.

## Acceptance criteria
- [ ] Model resolved via resolveTaskModel("extraction", workspaceId) against the ai_task_configs table (owned by 5.3) — this module does not hardcode "nvidia-nim" or a model string anywhere in its own code
- [ ] NVIDIA NIM call extracts: brand_mentioned, position, reasoning, sentiment, competitor_names_found, cited_domains, cited_domain_types
- [ ] Output validated against a strict zod schema before being written to the DB
- [ ] Runs as a step separate from the Gemini call — does not consume Gemini's grounding quota

## Tech
NVIDIA NIM (Llama 3.1 8B-Instruct class).

## AI usage
NVIDIA NIM free tier, 40 RPM (200 RPM available free on request).

## Caching
Not cached — each raw answer is unique per check, so there's nothing to reuse; kept cheap by using the free tier's generous RPM instead.

## Security
Never trust the model's JSON output as pre-validated; a malformed or off-schema response must be rejected and logged, not written through.
