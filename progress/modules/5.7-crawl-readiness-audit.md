## Purpose

Checks the customer's own site: robots.txt AI-bot rules, llms.txt presence, basic schema.org — zero AI cost.

## Tech

Server-side HTTP fetch + HTML/robots.txt parser. No AI model.

## AI usage

None.

## Caching

Cache per-domain audit result with a 24h TTL — a site's robots.txt/schema doesn't change minute to minute, no need to refetch on every dashboard load.

## Security

Identify your own crawler with a clear user-agent string; respect standard fetch etiquette when the target isn't the customer's own domain.
