## Purpose

Checks the customer's own site: robots.txt AI-bot rules, llms.txt presence, basic schema.org — zero AI cost.

## Acceptance criteria

- [x] Fetches and parses robots.txt for GPTBot/PerplexityBot/ClaudeBot/Google-Extended/CCBot rules — fixed 2026-07-27, verified via diff
- [ ] Checks for llms.txt (flagged as optional/experimental in the UI copy — no overclaiming its impact) — **still overclaims it (red/negative styling on missing); no pass/warning/fail abstraction exists yet**
- [x] Checks for basic schema.org presence and heading structure
- [ ] Outputs a plain checklist with fix instructions — **UI is now rendered (fixed 2026-07-27), but it's raw allowed/blocked badges, not a real checklist with fixInstructions — still missing `buildCrawlChecklist`**

## Tech

Server-side HTTP fetch + HTML/robots.txt parser. No AI model.

## AI usage

None.

## Caching

Cache per-domain audit result with a 24h TTL — a site's robots.txt/schema doesn't change minute to minute, no need to refetch on every dashboard load.

## Security

Identify your own crawler with a clear user-agent string; respect standard fetch etiquette when the target isn't the customer's own domain.
